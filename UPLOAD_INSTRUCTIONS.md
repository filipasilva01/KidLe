# Upload through the GitHub website

1. Open the `fix/prototype-improvements` branch in the `KidLe` repository.
2. Delete the old empty `space-inclusion` file and `tsconfig.tsbuildinfo` from the branch, if they are still visible. GitHub's upload page does not remove files that are missing from this folder.
3. Extract the ZIP and open the extracted `KidLe_fix_prototype_improvements` folder.
4. On GitHub, select **Add file → Upload files**.
5. Drag the contents of the extracted folder into the upload area. Upload the contents, not the ZIP itself and not the outer folder.
6. Use a commit message such as `Improve prototype interactions and documentation` and commit directly to `fix/prototype-improvements`.
7. Open a pull request with `space-inclusion` as the base branch and `fix/prototype-improvements` as the compare branch.

Do not describe this implementation as the prototype evaluated in the dissertation. It is a possible coded solution developed from the research findings.
